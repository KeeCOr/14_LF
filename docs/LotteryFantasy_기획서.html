Lottery Fantasy MVP

슬롯머신 × 타워 디펜스 — 릴을 돌려 카드를 뽑고 유닛을 배치하라

엔진: Unity 어셈블리: SlotDefense 장르: 전략 / 디펜스

1. 게임 개요

3개 릴(릴당 원소 1개: 화·철·생명)을 돌려 슬롯 결과에 따라 카드를 드로우하고, 드로운 카드로 유닛·스킬·건물을 배치해 적의 공격으로부터 마을(HP 1000)을 지키는 전략 게임.

마을 HP

1000

배틀 시간

180초

서바이벌: 무제한

핸드 크기

4장

2. 게임 모드

배틀 모드 (Battle)

  • 제한 시간: 180초
  • 시간 종료 시 HP 비교로 승패 결정
  • 플레이어 HP 선점 시 승리

서바이벌 모드 (Survival)

  • 제한 시간 없음 (99999초)
  • 마을 HP 0 될 때까지 지속
  • 최대한 오래 버티는 것이 목표

4. 원소 에너지 시스템

릴 결과로 원소 에너지(화·철·생명)가 적립되며, 카드 시전에 사용된다.

원소용도
화 (Fire)공격형 유닛 및 스킬 비용
철 (Iron)방어·건물 비용
생명 (Life)회복·버프 비용

5. 카드 시스템

카드 타입

Unit

전투 유닛 소환. HP·공격력·이동속도·사거리·공격속도·시야 스탯 보유. 공중 유닛 공격 및 비행 여부 포함.

Skill

즉발 스킬 효과. 범위 공격, 속도 증가, 자원 획득 등 다양한 스킬 이펙트.

Buff

글로벌 버프 적용. 전체 유닛 강화, 마을 회복, 에너지 생산 등.

Building

건물 배치. 생산 건물(자원 생성) 또는 전투 건물(타워 등).

카드 티어

Normal 일반

기본 스탯의 카드. 덱에서 주로 드로우.

Enhanced ★ 강화

Triple 슬롯 결과 시 드로우 가능한 강화 버전.

핸드 & 덱

  • 핸드: 최대 4장 유지 (빈 슬롯 생기면 덱에서 즉시 보충)
  • 덱: FixedDeckConfig로 사전 정의된 카드 풀에서 순서대로 드로우
  • 유닛 소환 시 해당 원소 비용 차감

8. UI 비주얼 퀄리티업 2026-05-15

런타임 생성 UI 구조는 유지하면서 공통 스타일 유틸을 추가해 HUD, 카드, 슬롯머신, 버튼, 모달의 색상과 상태 표현을 통일했다.

영역변경 방향
상단 HUD짙은 정보 바, HP 색상 강화, 덱 버튼 청색 accent 적용.
하단 패널카드 영역과 슬롯 영역을 분리하고 파란 테두리로 전투 UI 톤을 통일.
카드선택/사용 가능/부족/스킬/버프 상태별 배경색을 공통 팔레트로 정리하고 금색 상단 라인을 추가.
슬롯머신릴 박스 크기를 키우고 속성별 accent, STOP/AUTO 버튼 상태색, 행운 게이지 색을 강화.
모달결과와 덱 뷰어는 어두운 오버레이와 금색/청색 강조색으로 마감.

9. 오브젝트 및 캐릭터 에셋 2026-05-18

새 외부 다운로드보다 프로젝트에 이미 포함된 무료/샘플 에셋을 우선 사용한다. gameplay root의 Rigidbody2D, Collider2D, HpBar, 컨트롤러는 유지하고 로우폴리 모델과 자연 소품은 자식 장식 오브젝트로 붙인다.

영역사용 에셋
유닛Polytope Studio 로우폴리 캐릭터/장비 프리팹.
몬스터Polytope Studio 캐릭터 파츠를 일반/엘리트 구분 장식으로 사용.
기지SimpleNaturePack 자연 프리팹으로 마을 실루엣 강화.
포털Polytope Studio 목재/소품 프리팹을 relic 장식으로 사용.
전장SimpleNaturePack 나무, 바위, 덤불, 꽃과 울타리로 주변부 장식.

10. 예시 이미지 기반 전장 연출 2026-05-22

docs/LotteryFantasy_gameplay_preview.png의 밝은 캐주얼 판타지 방향을 기준으로 런타임 전장 장식을 보강했다. UI와 게임플레이 구조는 유지하고, 게임 시작 시 전장 바닥, 중앙 흙길, 석재 테라스, 진영 실루엣, 깃발과 금색 문장을 생성한다.

영역변경 방향
전장 배경밝은 녹색 전장, 먼 언덕, 중앙 흙길을 추가해 공간 깊이를 만든다.
플레이어/적 기지파랑/빨강 배너와 금색 문장을 배치해 진영 구분을 강화한다.
생존 모드적 기지 대신 보라색 포털 받침대 실루엣을 배치해 모드 목적을 명확히 한다.
구현 방식외부 다운로드 없이 코드 생성 SpriteRenderer와 기존 포함 에셋만 사용한다.
