# LotteryFantasy — Steam Store Description

## Short Description (30 words max)
확률 보상과 전투 선택이 맞물려 다음 전략을 바꾸는 슬롯 감각 판타지 게임.

## Long Description
LotteryFantasy는 확률 보상과 전투 선택이 맞물려 다음 전략을 바꾸는 슬롯 감각 판타지 게임입니다.

슬롯머신처럼 확률로 결정되는 보상 시스템과 전략적 전투 선택이 결합되어 매 판마다 새로운 전략을 요구합니다. 운과 전략이 균형 있게 맞물리는 독특한 게임플레이를 경험하세요.

판타지 세계관 속에서 확률과 전략으로 승리를 만들어 나가세요.

## Key Features
- 슬롯 감각의 확률 보상 시스템
- 전략적 전투 선택 메커니즘
- 운과 전략의 균형
- 판타지 세계관
